本地 Git 仓库推送说明
======================

当前 GitHub 连接器（CodeBuddy-Connector）的授权页不含仓库创建/写入权限，
因此无法通过连接器创建仓库或推送文件。请改用下面的本地 git + PAT 方式。

一、准备 GitHub Personal Access Token
--------------------------------------
1. 打开 https://github.com/settings/tokens
2. Generate new token -> Tokens (classic)
3. Note 随便填（如 matepad-reports），Expiration 按需选择
4. 勾选权限：repo（或仅 public_repo，如果仓库设为公开）
5. 生成后复制 token（只显示一次，务必保存好）

二、创建空仓库
--------------
打开 https://github.com/new
Repository name: matepad11-dby-w09-agent-reports
可见性：Public（之前已确认）
不要勾选 Initialize this repository with a README / .gitignore / license
点 Create repository

三、推送（在本目录执行）
------------------------
Git Bash 中依次执行（把 <TOKEN> 换成第一步的 token）：

  cd /d/workbuddy/2026-11-23-22-29-12/github_upload
  git remote add origin https://<TOKEN>@github.com/hhdy/matepad11-dby-w09-agent-reports.git
  git push -u origin HEAD:main

如果远端默认分支是 master，把上面的 main 换成 master；
或者先在网页建仓时选 main 为默认分支。

四、推送后清除 URL 中的 token（重要）
------------------------------------
  git remote set-url origin https://github.com/hhdy/matepad11-dby-w09-agent-reports.git

五、验证
--------
打开 https://github.com/hhdy/matepad11-dby-w09-agent-reports
确认 round1-adb / round2-adb / firmware-hos43 三个目录及 README.md 均已上传。

备注：本目录已 git init 并完成首次 commit，推送前无需再 add/commit。
78 MB 的固件镜像 ZIP 不在本目录，也未计划上传。
