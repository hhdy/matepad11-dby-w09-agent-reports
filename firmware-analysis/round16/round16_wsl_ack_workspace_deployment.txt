11. ENVIRONMENT-LEVEL CHANGES MADE (disclosed for review)
--------------------------------------------------------------------------------
  E1. Installed distro "Ubuntu-24.04" (Ubuntu 24.04.5 LTS, WSL 2) at
      D:\WSL\Ubuntu-24.04 via the documented command
        wsl --install --distribution Ubuntu-24.04 --location "D:\WSL\Ubuntu-24.04"
            --no-launch
      The pre-existing "Ubuntu" distro on C: was left untouched.
  E2. Linux account created non-interactively: kerneldev (uid 1000, sudo,
      locked password), and /etc/wsl.conf set to
        [user] default=kerneldev
      Rationale: the agent has no channel for a private interactive password
      prompt, and leaving the distro without a default user would have made
      passwordless root the everyday login context, which the task prohibits.
      The password itself is deliberately unset and left to the operator.
  E3. Windows-side WSL configuration file created:
        <user profile>\.wslconfig  containing  [wsl2] networkingMode=mirrored
      Rationale: in the default NAT mode the VM cannot reach the host's
      loopback proxy, and android.googlesource.com was unreachable directly
      from the VM (TCP connect timeout). Mirrored networking is a documented
      Microsoft mode; it lets the VM use the host network path and reach the
      official sources without any third-party mirror. Measured effect: direct
      HTTPS to android.googlesource.com returns HTTP 200 afterwards. To revert,
      delete that line and run `wsl --shutdown`. No firewall rule, proxy LAN
      exposure, security product or policy was modified.
