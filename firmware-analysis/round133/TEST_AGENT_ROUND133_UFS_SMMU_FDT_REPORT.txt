      (parse_fdt_header / decode_structure)。
    - 为取得 phandle 与 fixup 所需的原始属性字节, 另实现同 token 语法的
      value-preserving 解码 (BEGIN_NODE/END_NODE/PROP/NOP/END, 4 字节对齐,
      string block 边界检查), 并对每个输入做一致性交叉校验:
      node 数一致 且 每个路径的属性名集合完全一致 -> 全部 12 个文件 crosscheck=True。
    - phandle 解析: 建立 phandle/linux,phandle -> 节点路径映射 (重复值检测)。
    - overlay 解析: fragment target 原始值为 0xFFFFFFFF 占位, 由 __fixups__ 中
      symbol -> "/fragment@N:target:0" 定位, 再用 base FDT 的 __symbols__ 把
      symbol 解析为真实 base 节点路径; 不使用节点名猜测。
    - 不解析、不推断 ABL 实际选择哪一份 DTBO。
